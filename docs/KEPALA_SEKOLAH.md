# Detail Fitur — Dashboard Kepala Sekolah (F-KEPSEK)

Dokumen ini berisi spesifikasi kebutuhan fungsional Executive Dashboard untuk Kepala Sekolah.

---

## 1. Spesifikasi Fitur

*   **F-DASH-KEPSEK-01: Grafik Tren Kehadiran Sekolah**
    *   Grafik garis (*line chart*) interaktif yang menyajikan tren rata-rata kehadiran harian tingkat sekolah per bulan sepanjang tahun ajaran berjalan.
*   **F-DASH-KEPSEK-02: Ekspor Rekap Sekolah Terpadu**
    *   Tombol unduh laporan rekapitulasi sekolah keseluruhan berformat Excel terpadu (setiap kelas dipisahkan secara otomatis per sheet/tab di dalam satu file Excel).
*   **F-DASH-KEPSEK-03: Peringkat Disiplin Kelas (Leaderboard)**
    *   Widget pemeringkatan kelas terdisiplin (Top 3 Kelas Kehadiran Tertinggi) dan peringkat terbawah (Bottom 3 Kelas Kehadiran Terendah/Butuh Pembinaan) berdasarkan persentase kehadiran bulanan.
*   **F-DASH-KEPSEK-04: Diagram Donat Distribusi Harian**
    *   Diagram donat (*donut chart*) yang memvisualisasikan pembagian persentase status kehadiran harian sekolah saat itu secara langsung (Hadir, Terlambat, Sakit/Izin, Alpha).
*   **F-DASH-KEPSEK-05: Monitor Kinerja Piket**
    *   Widget pemantau nama Guru Piket yang aktif bertugas hari ini beserta jumlah input manual yang berhasil dilakukannya sebagai kontrol operasional.
